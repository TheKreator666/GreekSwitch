# Phonetic index (loanword matching)

`en.idx` holds English words with their pronunciations in the shared phoneme alphabet of
`GreekSwitch.Core.Loanwords` (`Phoneme`), plus the consonant-skeleton and one-deletion indexes
that find candidates for a Greek word (`docs/loanword-design.md`). It is generated by
`tools/PhoneticIndexBuilder`, committed, embedded in GreekSwitch.Core, and read by
`PhoneticIndex.FromEmbeddedResources()` as flat arrays: nothing is parsed as text at run time.

| | |
|---|---|
| Words | 31,934: the words of `data/frequency/en.tsv` (top ~50k English words by Zipf) that are a–z only, at least 3 letters, a lowercase entry of en_US (names such as `maria` are left out) and in CMUdict |
| Pronunciations | 34,792 (up to 2 per word) |
| Size | 2.4 MB on disk and in memory; loads in ~15 ms |

## Source

The **CMU Pronouncing Dictionary**, `cmudict.dict` from https://github.com/cmusphinx/cmudict
(commit `0f8072f814306c5ee4fbf992ed853601b12c01f9`, 2024-12-17; file SHA-256
`81917843c7f44ce2b094ac63873c2c7a4cf802040792c455ba3ca406891c3d22`). BSD-style license, Copyright
(C) 1993-2015 Carnegie Mellon University; see THIRD_PARTY_NOTICES.md. The dictionary itself is
not committed: download it to regenerate. Word frequencies come from `data/frequency/en.tsv`
(wordfreq, CC BY-SA 4.0), stored here as one byte per word.

ARPAbet is mapped as in `ArpabetPhonetics` (vowels collapse onto a e i o u; ER = e r, EY = e i;
Y is the semivowel y; NG = n g, but n before K/G). Stress is the primary-stress vowel, counted
from the last vowel.

## Format (v1, little-endian)

```
"GSPI"                     4 bytes, ASCII
version                    1 byte (= 1)
counts                     6 × int32: words, entries, word bytes, phoneme bytes, skeleton pairs, deletion pairs
word offsets               int32[words + 1] into the word bytes
word bytes                 UTF-8, concatenated
zipf                       byte[words], Zipf × 25
entry word                 int32[entries], the word of each pronunciation
entry offsets              int32[entries + 1] into the phoneme bytes
entry stress               sbyte[entries], stressed vowel counted from the end, -1 if none
phoneme bytes              byte per Phoneme value
skeleton keys / entries    uint32[] sorted + int32[]: FNV-1a of each entry's consonant skeleton
deletion keys / entries    uint32[] sorted + int32[]: the skeleton with each one consonant deleted
```

The `Phoneme` byte values are part of the format: only append to the enum.

## Regenerating

```bash
curl -L -o cmudict.dict https://raw.githubusercontent.com/cmusphinx/cmudict/master/cmudict.dict
dotnet run --project tools/PhoneticIndexBuilder -c Release -- --cmudict cmudict.dict
#   [--freq data/frequency/en.tsv] [--out data/phonetic/en.idx] [--max-pronunciations 2]
```

Regenerate after changing `ArpabetPhonetics`, `PhoneticSkeleton`, the `Phoneme` enum, the
English frequency list or the English lexicon, and commit `en.idx`.
