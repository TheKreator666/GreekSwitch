# Trigram models

`el.tri` and `en.tri` are character trigram counts generated by `tools/NgramBuilder`. They are
committed so building the app never requires running the tool, and they are embedded in
`GreekSwitch.Core` as resources.

## Format (v1)

UTF-8 text, LF line endings:

```
# GreekSwitch trigram model v1          <- required header
# lang=el words=812194 trigrams=6432    <- informational comments start with '#'
^^α	139370                              <- trigram, TAB, count
```

- Each data line is exactly three characters, a TAB, and a decimal count.
- Words are normalized before counting by `GreekSwitch.Core.Text.TrigramText`. Greek is lowercased,
  has its tonos and dialytika removed, and maps ς to σ, leaving the alphabet α–ω. English is
  lowercased, with the alphabet a–z plus `'`.
- Each word is padded as `^^word$`, so `^^x` counts word starts and `xy$` counts word endings.
- The scorer applies add-k smoothing (k = 0.1) and averages the log probability over the
  predicted characters.

## Regenerating

```bash
dotnet run --project tools/NgramBuilder -c Release -- --lang el \
  --aff data/dictionaries/el_GR.aff --dic data/dictionaries/el_GR.dic --out data/ngrams/el.tri
dotnet run --project tools/NgramBuilder -c Release -- --lang en \
  --aff data/dictionaries/en_US.aff --dic data/dictionaries/en_US.dic --out data/ngrams/en.tri
```

The training text is the Hunspell word lists themselves. Every stem is expanded with its
PFX/SFX rules, and each distinct form is counted once. That measures how often a trigram
appears across the vocabulary, not in running text. To add a real corpus later, pass one or
more `--corpus file.txt` arguments (plain UTF-8; every word token is counted). The corpus
counts are added to the dictionary counts.
